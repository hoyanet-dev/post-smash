# 💥 Post Smash

내가 지정한 게시글/공고만 골라서 **완전히 안 보이게** 만드는 크롬 확장 프로그램.

- 회사·키워드 단위 일괄 차단이 아니라, **클릭한 항목 하나**만 숨깁니다.
- 흐리게 처리하지 않고 `display: none`으로 지웁니다.
- 잡코리아뿐 아니라 목록형 페이지라면 어디서든 동작하도록 만들었습니다 (사이트별 검증은 진행 중).

## 설치 (개발자 모드)

1. 이 저장소를 clone 하거나 zip으로 받습니다.
2. 크롬에서 `chrome://extensions` 를 엽니다.
3. 우측 상단 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더를 선택합니다.

## 사용법

1. 목록 페이지에서 확장 아이콘 → **Smash 모드 켜기**
2. 숨길 항목에 마우스를 올리면 빨간 테두리가 뜨고, 클릭하면 사라집니다. (`Esc`로 종료)
3. 숨긴 항목은 팝업 목록에서 **복원**할 수 있습니다.

## 동작 방식

- 항목 안의 링크에서 사이트 자체 ID(경로, 숫자 쿼리 파라미터)를 뽑아 키로 씁니다.
- 같은 목록의 다른 항목에도 있는 링크(회사 링크 등)는 키에서 제외합니다.
- 데이터는 `chrome.storage.local`에만 저장되며 외부로 전송하지 않습니다.
