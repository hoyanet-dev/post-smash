# 💥 Post Smash

내가 지정한 게시글/공고만 골라서 **완전히 안 보이게** 만드는 크롬 확장 프로그램.

- 회사·키워드 단위 일괄 차단이 아니라, **클릭한 항목 하나**만 숨깁니다.
- 흐리게 처리하지 않고 `display: none`으로 지웁니다.
- 잡코리아뿐 아니라 목록형 페이지라면 어디서든 동작하도록 만들었습니다 (사이트별 검증은 진행 중).

## 설치 (개발자 모드)

1. 이 저장소를 clone 하거나 zip으로 받습니다.
2. 크롬에서 `chrome://extensions` 를 엽니다.
3. 우측 상단 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더를 선택합니다.

## 사용법

### 1. 항목 숨기기
1. 숨기고 싶은 공고/게시글이 있는 **목록 페이지**를 엽니다. (설치 직후라면 한 번 새로고침하세요.)
2. 툴바의 💥 Post Smash 아이콘을 눌러 **Smash 모드 켜기**를 클릭합니다.
   - 화면 위쪽에 빨간색 "💥 Smash 모드" 안내가 뜨면 켜진 상태입니다.
3. 숨길 항목 위에 마우스를 올립니다. 한 항목 전체에 빨간 테두리가 표시됩니다.
4. 그 항목을 **클릭**하면 바로 사라집니다. (링크로 이동하지 않습니다.)
5. 계속 다른 항목을 클릭해서 더 숨길 수 있습니다.
6. 끝나면 `Esc` 키를 눌러 Smash 모드를 끕니다.

### 2. 숨긴 항목 확인 / 복원
1. 숨긴 사이트에서 툴바 아이콘을 누릅니다.
2. 팝업에 해당 사이트에서 숨긴 항목 목록이 나옵니다. (최근 순)
3. 항목 오른쪽 **복원** 버튼을 누르면 다시 보입니다.

### 3. 참고
- 새로고침하거나 스크롤로 새 항목이 로드돼도 숨김 상태가 유지됩니다.
- 숨김은 **공고 하나 단위**입니다. 같은 회사의 다른 공고는 그대로 보입니다.
- 항목이 잡히지 않으면(빨간 테두리가 안 뜨면) 그 사이트에서는 아직 지원되지 않는 구조일 수 있습니다. 이슈로 남겨 주세요.
- 확장 프로그램을 삭제하면 숨김 목록도 함께 사라집니다.

## 동작 방식

- 항목 안의 링크에서 사이트 자체 ID(경로, 숫자 쿼리 파라미터)를 뽑아 키로 씁니다.
- 같은 목록의 다른 항목에도 있는 링크(회사 링크 등)는 키에서 제외합니다.
- 데이터는 `chrome.storage.local`에만 저장되며 외부로 전송하지 않습니다.
